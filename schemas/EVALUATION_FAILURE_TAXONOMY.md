# Evaluation failure taxonomy

`EXACT`, `VALUE_WRONG`, `STATUS_WRONG`, `NOT_EXTRACTED`, `FALSE_NR`,
`FALSE_PRESENT`, `ENTITY_MISSING`, `ENTITY_EXTRA`, `ENTITY_AMBIGUOUS`,
`ARM_BINDING_UNRESOLVED`, `OUTCOME_IDENTITY_SPLIT`, `OUTCOME_IDENTITY_MERGE`,
`COMPARATOR_SCOPE_UNRESOLVED`, `SOURCE_CONFLICT_DETECTED`,
`SOURCE_CONFLICT_MISSED`, `SOURCE_CONFLICT_SPURIOUS`, `EVIDENCE_UNGROUNDED`,
and `REQUIRED_BUT_UNSUPPORTED`.

This PR freezes names and denominator semantics only. It does not implement
classification or scoring.
